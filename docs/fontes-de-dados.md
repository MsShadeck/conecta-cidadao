## Prefeitura de Indaiatuba

- **Não há `robots.txt`**: o endereço devolve a página inicial em HTML. Mesmo assim, a política
  adotada é de **leitura manual e pontual**, sem scraping automatizado.
- **O site responde 200 até para URL inexistente** (soft 404). Por isso, conferir um link exige ler o
  conteúdo da página; o status HTTP não basta.
- Links conferidos (a página tem o título esperado): Carta de Serviços, Horários de ônibus, Transporte
  coletivo, Ponto Cidadão, Indaiatuba by Bike, Minha Vacina, Defesa Civil, Fale conosco, Tributos,
  Imprensa Oficial, Transparência, Adoção de animais, Mapa turístico (PDF), Minha Indaiatuba, Geolux e
  Consulta Cidadão (autuações).
- A página "Terminais e pontos de embarque" existe, mas **está sem conteúdo**.

## Cittati: programação oficial das linhas (SOU Indaiatuba)

- A página "Horários de ônibus" da Prefeitura aponta para `programacao.cittati.com.br`, sistema da
  operadora. O `robots.txt` dele libera o acesso (`Disallow:` vazio).
- O app consome uma API interna (`/api/companyLine/all`, `/api/timetable/timetabletriproute/{id}`,
  `/api/timetable/timetableuser/{id}`) autenticada pelo token que vai no próprio link da Prefeitura.
- Uma consulta à lista de linhas (08/10/2026) devolveu **38 linhas reais**, de 301 a 336, incluindo
  a 310-1 e a 313-1.
- **Status: uso bloqueado até haver autorização.** É uma API não documentada de terceiro. Antes de
  automatizar, é preciso pedir permissão à SOU Indaiatuba ou à Secretaria de Mobilidade, ou obter o
  GTFS diretamente delas.
